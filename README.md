# signalk-doctor

Diagnostic and health-check plugin for [SignalK Node Server](https://signalk.org/).

**Status:** skeleton — name reserved on npm, implementation pending.

## Planned scope

Surface common SignalK server issues in one place:

- Connection / interface health (NMEA 2000, NMEA 0183, etc.)
- Delta throughput and stalls
- Plugin status summary
- Disk, memory, and log indicators

## Install

Not ready for use. Once published with real functionality, install via the SignalK Appstore as `signalk-doctor`.
